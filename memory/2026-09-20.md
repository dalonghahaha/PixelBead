## Lessons learned (this session)

<!-- observed: 2026-09-20 | status: active -->

- **Never use `***` as placeholder in code**: 编辑 TypeScript 时,placeholder `***` 被字面写入,造成语法错误。改用真实类型/默认值或具体变量名
- **Whitespace-sensitive edits**: read file before edit to match exact indentation, 否则 `old_string not found` 失败
- **Multi-option "A"**: 用户单字母响应默认接受 AI 推荐选项(无需问清哪一个)
- **Batch edits strategy**: 多个文件并行 read + write 优于串行,节省 context
- **Cross-spec consistency**: 数据模型 / API 契约 / 命名规范跨 spec 一致性是 spec-kit 阶段 8(analyze)的核心价值
- **Progressive MVP > aggressive refactor**: 005 URL 前缀重构留 P2,渐进式上线双语,降低回归风险
