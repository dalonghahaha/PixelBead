2. **pypindou API 名错** — plan 写 `image_to_pattern`,实际是 `generate_pattern(image, *, width, height, palette='mard-221-alfonse-doudou', ...)`。

## 待办 / 已知 issue

1. **Lighthouse perf in dev mode = 46** — Next.js dev 不优化是预期。要拿 ≥90 必须 production 模式,但 `next start` 在本环境报 Server Action bug(Next.js 14 已知问题),需要升级 Next.js 或改 standalone 部署。
2. **Cookie 镜像方案** — 现在 web 端多写一个 cookie 镜像 JWT,生产前最好改 `Set-Cookie: HttpOnly` 由 apps/api 写,避免 localStorage XSS 风险。
3. **favicon.svg 是老孙手画** — 8×8 拼豆 "P" 业余水平,等大龙定稿后替换。
